# Telegram-бот «Напоминалка»

Telegram-бот на Python, который сохраняет напоминания и присылает уведомления в назначенное время.

## Возможности

- Команда /start — приветствие и инструкция
- Команда /remind ГГГГ-ММ-ДД ЧЧ:ММ текст — добавить напоминание
- Команда /list — показать все активные напоминания
- Команда /delete номер — удалить напоминание
- Проверка: нельзя поставить напоминание на прошедшее время
- Напоминание придёт, даже если бот был выключен в нужную минуту
- Часовой пояс настраивается (по умолчанию Москва), работает на любом сервере
- Автоматическая отправка уведомлений в назначенное время
- Хранение напоминаний в базе данных SQLite (не теряются при перезапуске)

## Пример использования

/remind 2026-10-15 18:30 позвонить маме

Бот ответит:

Ок! Напомню 15.10.2026 в 18:30: позвонить маме

А в назначенное время пришлёт:

⏰ Напоминание: позвонить маме

## Технологии

- Python 3
- pyTelegramBotAPI — работа с Telegram Bot API
- SQLite — хранение напоминаний
- threading — фоновый планировщик (доступ к базе защищён замком Lock)
- zoneinfo — работа с часовыми поясами
- python-dotenv — загрузка токена из .env

## Установка и запуск

1. Клонируй репозиторий:

git clone https://github.com/alex05ru-wq/reminder_bot.git
cd reminder_bot

2. Установи зависимости:

pip install -r requirements.txt

3. Создай файл .env и добавь токен от @BotFather:

BOT_TOKEN=твой_токен
TIMEZONE=Europe/Moscow

(TIMEZONE необязателен, по умолчанию Europe/Moscow)

4. Запусти бота:

python bot.py

5. Открой бота в Telegram и напиши /start.

## Как это работает

1. Пользователь пишет /remind ... — бот сохраняет напоминание в базу данных SQLite.
2. Фоновый поток (threading) каждые 30 секунд проверяет базу: есть ли напоминания, время которых уже наступило или прошло?
3. Если есть — бот отправляет уведомление и удаляет напоминание из базы.
